7- ملف جافاسكربت خارجي

External JavaScript - من هرمش

📄 script.js document.getElementById('demo').innerHTML = 'This text is added by JavaScript';
document.getElementById('demo').style.color = 'red';
📄 index.html <p id="demo">This text will be changed...</p>
<script src="script.js"></script>
This text will be changed when the script is executed.
✅ الفكرة:

وضعنا الكود في ملف خارجي اسمه script.js واستدعيناه في آخر الصفحة. هذه أفضل طريقة لتنظيم المشروع!
